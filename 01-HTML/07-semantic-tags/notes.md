# Semantic Tags in HTML

Semantic tags clearly describe the meaning of content.

They make code more readable and improve SEO.

---

# Header Tag

```html
<header></header>
```

Used for website header section.

---

# Nav Tag

```html
<nav></nav>
```

Used for navigation links.

---

# Main Tag

```html
<main></main>
```

Represents main content of webpage.

---

# Section Tag

```html
<section></section>
```

Used to divide webpage into sections.

---

# Article Tag

```html
<article></article>
```

Used for independent content.

Example:
- Blog post
- News article

---

# Footer Tag

```html
<footer></footer>
```

Used for footer section.

---

# Example Layout

```html
<header>
    <h1>Website</h1>
</header>

<nav>
    <a href="#">Home</a>
</nav>

<main>
    <section>
        <article>
            Content
        </article>
    </section>
</main>

<footer>
    Footer
</footer>
```

---

# Advantages of Semantic Tags

- Better readability
- Better SEO
- Easier maintenance
- Helpful for screen readers
