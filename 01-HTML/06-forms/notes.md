    # HTML Forms

Forms are used to collect user data.

---

# Form Tag

```html
<form></form>
```

Used to create forms.

---

# Input Tag

```html
<input type="text">
```

Used to take user input.

---

# Common Input Types

## Text Input

```html
<input type="text">
```

---

## Password Input

```html
<input type="password">
```

Hides entered text.

---

## Email Input

```html
<input type="email">
```

Used for email addresses.

---

## Number Input

```html
<input type="number">
```

Used to enter numbers.

---

## Date Input

```html
<input type="date">
```

---

# Label Tag

```html
<label>Name:</label>
```

Used to display label for inputs.

---

# Radio Button

```html
<input type="radio">
```

Allows selecting one option.

---

# Checkbox

```html
<input type="checkbox">
```

Allows selecting multiple options.

---

# Placeholder Attribute

```html
placeholder="Enter your name"
```

Shows hint text inside input.

---

# Button Tag

```html
<button>Submit</button>
```

Used to create button.

---

# Example

```html
<form>

    <label>Email:</label>
    <input type="email">

    <button>Submit</button>

</form>
```
