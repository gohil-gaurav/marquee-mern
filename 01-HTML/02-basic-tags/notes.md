# Basic HTML Tags

## Heading Tags

Heading tags are used to create headings in HTML.

```html
<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>
```

### Important Points
- h1 is the biggest heading
- h6 is the smallest heading
- Headings help organize content

---

# Paragraph Tag

Paragraph tag is used to write text content.

```html
<p>This is paragraph tag</p>
```

### Example

```html
<p>HTML is very easy to learn.</p>
```

---

# Comment Tag

Comments are ignored by the browser.

```html
<!-- This is comment -->
```

### Uses of Comments
- Explain code
- Make code readable
- Hide temporary code
