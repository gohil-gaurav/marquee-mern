# HTML Lists

Lists are used to organize items in HTML.

---

# Ordered List

Ordered list displays items with numbers.

```html
<ol>
    <li>Item 1</li>
    <li>Item 2</li>
</ol>
```

## Example

```html
<ol>
    <li>Wake Up</li>
    <li>Study</li>
</ol>
```

---

# Unordered List

Unordered list displays items with bullets.

```html
<ul>
    <li>Apple</li>
    <li>Mango</li>
</ul>
```

---

# List Item Tag

`<li>` tag is used inside lists.

```html
<li>HTML</li>
```

---

# Nested List

List inside another list is called nested list.

```html
<ul>
    <li>Frontend
        <ol>
            <li>HTML</li>
            <li>CSS</li>
        </ol>
    </li>
</ul>
```

---

# Important Points

- `<ol>` → Ordered List
- `<ul>` → Unordered List
- `<li>` → List Item
- Lists help organize content
