# HTML Introduction

## What is HTML?

HTML stands for **HyperText Markup Language**.

It is used to create the structure of web pages.

---

# HTML Boilerplate

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>

</body>
</html>
```

---

# Important Tags

## Heading Tags

```html
<h1>This is Heading</h1>
<h2>This is Heading</h2>
```

- h1 is biggest heading
- h6 is smallest heading

---

## Paragraph Tag

```html
<p>This is paragraph tag</p>
```

Used to write paragraphs.

---

## List Tags

### Ordered List

```html
<ol>
    <li>Apple</li>
    <li>Mango</li>
</ol>
```

### Unordered List

```html
<ul>
    <li>Apple</li>
    <li>Mango</li>
</ul>
```

---

# Shortcut

## Boilerplate Shortcut

```txt
! + Enter
```

Used to generate HTML boilerplate in VS Code.
