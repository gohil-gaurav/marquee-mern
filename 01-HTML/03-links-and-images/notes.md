# Links and Images in HTML

# Anchor Tag

Anchor tag is used to create links in HTML.

```html
<a href="https://www.google.com">
    Visit Google
</a>
```

---

# Important Attributes of Anchor Tag

## href

Used to add link URL.

```html
href="https://example.com"
```

## target="_blank"

Opens link in new tab.

```html
<a href="https://youtube.com" target="_blank">
    Open YouTube
</a>
```

---

# Image Tag

Image tag is used to display images.

```html
<img src="image.jpg" alt="Image">
```

---

# Important Attributes of Image Tag

## src

Used to provide image path.

```html
src="image.jpg"
```

## alt

Alternative text shown if image does not load.

```html
alt="Nature Image"
```

## width

Used to set image width.

```html
width="300"
```

---

# Example

```html
<img 
    src="https://example.com/image.jpg"
    alt="Sample Image"
    width="400"
>
```
