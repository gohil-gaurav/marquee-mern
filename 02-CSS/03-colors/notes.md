# CSS Colors

CSS colors are used to style text and backgrounds.

---

# 1. Color Names

```css
color: red;
```

Examples:
- red
- blue
- green
- yellow
- black

---

# 2. RGB Colors

RGB stands for Red, Green, Blue.

```css
color: rgb(255, 0, 0);
```

Format:

```css
rgb(red, green, blue)
```

Range:
- 0 to 255

Example:

```css
color: rgb(0, 128, 255);
```

---

# 3. HEX Colors

HEX colors start with #.

```css
color: #ff0000;
```

Examples:

```css
#ff0000
#00ff00
#0000ff
#ffffff
#000000
```

---

# 4. Background Color

Used to change element background.

```css
background-color: yellow;
```

Example:

```css
p {
    background-color: yellow;
}
```
