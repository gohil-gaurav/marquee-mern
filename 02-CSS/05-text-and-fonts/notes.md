# CSS Text and Fonts

## Introduction

Text and Font properties are used to control the appearance of text on a webpage.

---

# text-align

Controls horizontal alignment of text.

```css
text-align: left;
text-align: center;
text-align: right;
```

Example:

```css
h1{
    text-align:center;
}
```

---

# text-transform

Changes letter casing.

```css
text-transform: uppercase;
text-transform: lowercase;
text-transform: capitalize;
```

Example:

```css
p{
    text-transform:uppercase;
}
```

---

# text-decoration

Adds decoration to text.

```css
text-decoration: underline;
```

Examples:

```css
underline
overline
line-through
none
```

---

# font-size

Controls text size.

```css
font-size:30px;
```

---

# font-weight

Controls thickness of text.

```css
font-weight:bold;
```

Common Values:

```css
normal
bold
100-900
```

---

# font-family

Changes font style.

```css
font-family:Arial, sans-serif;
```

Example:

```css
font-family:Georgia, serif;
```

---

# line-height

Controls spacing between lines.

```css
line-height:2;
```

---

# Complete Example

```css
p{
    font-family:Arial;
    font-size:20px;
    font-weight:bold;
    text-align:center;
}
```

---

# Interview Questions

## Difference between font-size and font-weight?

| font-size | font-weight |
|------------|------------|
| Controls text size | Controls text thickness |

---

## What is font-family?

Font-family specifies which font should be used for text.

Example:

```css
font-family:Arial, sans-serif;
```
